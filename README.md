# 风吟（工作名）

面向电吹管用户的 Windows 中文软音源宿主。项目已经包含交互原型，以及正式 C++/JUCE 原生工程的第一版骨架。

## 当前可以体验的内容

- 中文演奏主界面
- 模拟电吹管气息、音高、左右声道电平和频谱
- 多彩跑马灯及三种视觉主题
- 本地视频选择、播放、暂停、进度和音量控制
- 音色方案选择和收藏
- 设备、声音、插件和激活设置页面
- 本机唯一激活码与永久离线授权
- 低性能模式与动画自动降级逻辑

## 如何预览

直接双击 `prototype/index.html` 即可。如果浏览器限制本地视频，可在本目录运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/prototype/`。

## 重要说明

网页原型使用模拟数据展示完整交互。原生程序已经可以检测真实 MIDI 和音频设备，并已接入 VST3 扫描、加载、SWAM 分类和本地视频播放器。实际 SWAM 发声仍需在安装正版插件的 Windows 电脑上验证。

## 原生工程

`native/` 已包含第一版真实 MIDI 输入服务：设备枚举、自动连接、音符、力度、CC2 气息和平滑后的弯音状态。没有设备时界面自动显示模拟数据。还包含音频输出设备、采样率、缓冲区和预计延迟管理服务。

自动识别目前覆盖 Roland Aerophone、Yamaha YDS、Akai EWI、Aodyo Sylphyo 和通用 MIDI 电吹管。首次使用向导可通过一段长音自动判断最可能的气息控制器。

“连接向导”现已接入原生界面：自动列出 MIDI 设备，允许直接使用常见的 CC2、CC11、CC1，或进行 6 秒长音识别。软件会排除延音踏板等误判，并要求控制范围和连续变化达到阈值。成功选择的设备和每台设备各自的气息 CC 会自动记忆。

“吹奏调节”提供面向普通用户的三档式设置：气息响应、平滑程度、起音门槛和弯音灵敏度。每项都有中文效果说明和推荐档，也可一键恢复推荐；底层参数会安全地同步到 MIDI 处理线程，并按电吹管分别记忆。

构建依赖由 CMake 自动获取。正式 Windows 构建将使用 Visual Studio 2022 和 CMake；开发阶段固定 JUCE 9.0.2，产品发布前需确认 JUCE 商业许可。

Windows 交付流程已自动化。在 Windows 11 x64 电脑安装 Visual Studio 2022（勾选“使用 C++ 的桌面开发”）和 Inno Setup 6 后，右键用 PowerShell 运行 `scripts/build-windows.ps1`，脚本会依次完成 Release 编译、自动测试、客户文件安全检查和中文安装包生成。最终客户安装包位于 `dist/installer/`；`dist/店主激活工具/` 只供销售者本人保存，绝不能发给客户。

客户版使用静态 MSVC 运行库，并在 Windows 开启 JUCE 的 ASIO 支持，以减少额外运行库安装和降低专业声卡延迟。安装器支持 64 位 Windows、中文向导、开始菜单快捷方式和可选桌面快捷方式；卸载时保留用户的激活、音色方案和录音数据。

当前原生程序已在 macOS ARM 环境完成 Debug 全量编译和启动检查，启动时 MIDI、音频设备和中文界面初始化均正常。

“设备设置”按钮已接入简化中文面板，可选择声音驱动、输出设备、44100/48000/96000 Hz 采样率和 64/128/256/512 缓冲区。界面直接标出适合电吹管的推荐值；设置会自动保存并在下次启动恢复。切换设备前若正在录音，软件会先安全停止并保存。
声音驱动、输出设备、采样率和缓冲区已直接放在“声音设置”页，选择后立即应用并保存；应用失败时会自动恢复上一个可用配置。
首次运行会优先使用 Windows Audio 低延迟模式、48000 Hz 和 128 采样缓冲，不支持时会自动回退；用户手动应用过声音设置后不再自动覆盖。

原生程序目前已经打通 MIDI → 无锁命令队列 → 实时音频回调 → 内置测试音源的链路，并建立了 VST3 后台扫描目录、缓存和故障恢复骨架。

VST3 实例播放器已支持异步加载、MIDI 音符、CC2/CC11 气息、弯音以及插件状态保存和恢复。SWAM 插件可从普通插件目录中自动筛选并按乐器家族分类；实际 SWAM 发声仍需在安装了正版 SWAM 的测试电脑上验证。

原生界面现已提供“扫描音源、选择音源、加载音源、保存当前音色、载入方案”。音色方案使用插件唯一标识重新定位插件，并以原子文件替换方式保存插件二进制状态和气息设置。

插件扫描结果现在会自动区分音源与效果器。演奏链路支持“电吹管 → SWAM/VST3 音源 → 一个 VST3 效果器 → 声卡与录音”，可随时加载、替换或移除效果器。音色方案格式已升级到第 2 版，会同时保存音源状态、效果器身份和效果器内部参数，并兼容旧方案。

音色方案已支持自定义中文名称、收藏置顶、设为启动默认和二次确认删除。插件扫描缓存存在时，永久版会在启动后自动恢复默认音源、效果器、旁通状态、气息设置和总音量。

音源和效果器都可以打开其原始插件界面；没有自带界面的插件会显示通用参数面板。效果器支持一键旁通，旁通状态与总音量会随音色方案保存。总输出已增加真实左右声道峰值检测，主界面的电平显示由最终混音数据驱动。

演奏主界面的 54 段频谱已改为读取最终混音，通过无锁 FIFO 和 2048 点 FFT 计算 45Hz～18kHz 的对数频段。没有连接设备时保留柔和的演示动画，连接后自动切换真实数据。

0.7.1 完善“吹管本调 → 目标演奏调”的绝对换算。连接后普通吹奏不会被误当成校准；用户第一次使用移调时，软件会用直白弹窗引导其按 C（Do）指法吹一个音，识别成功后才启用移调。吹管本调不会跨连接保存，避免用户在设备上改调后沿用旧值。软件设置页同时增加本机码一键复制，方便远程安装激活。

0.7.2 修复部分 Windows 笔记本连接耳机或音响后，视频与软音源输出到不同设备的问题：普通 Windows 音频模式会在视频播放时跟随系统默认输出。视频区增加始终可见的“选择视频／更换视频”按钮，并修复窗口模式下选择按钮被画面层遮挡的问题。

0.7.3 将伴奏音轨接入风吟内部混音总线，录音会同时保存软音源和视频伴奏；播放、暂停、跳转和音量由视频画面与后台音轨同步。智能音频优化会对齐 48 kHz、关闭无用输入并选择适合当前驱动的实时缓冲，检测到连续丢音后会在空闲时自动提高一级稳定性。

0.7.4 新增声音设备自动配置：普通 Windows 电脑首次运行优先使用低延迟模式、48 kHz 和 128 采样缓冲，不稳定时安全回退至256。声音设置页改为内嵌式即时操作，驱动、输出设备、采样率和缓冲区选择后立即生效并保存，失败时自动恢复上一可用配置。演奏页启动时默认将“气息与声音”区域收至最低，保留手动拖动调节。

0.7.5 修复 0.7.4 可能被旧手动设置锁在普通 Windows Audio、48 kHz / 512 缓冲的问题。升级后会自动迁移这类旧配置；“自动优化”现在会真正切换至 Windows Audio (Low Latency Mode)，优先选择设备实际支持的 128 或最接近低延迟缓冲，并在设备只上报单一参数时给出明确说明。

首次启动会显示逐项使用向导，按“永久激活 → 电吹管连接 → 声音设备 → SWAM 扫描”判断当前缺少的下一步，每次只处理一个问题。完成后不再自动弹出，顶部“使用向导”可随时重新打开。

本地视频面板已支持 MP4/MOV/M4V 的异步加载、播放、暂停、停止、进度拖动、时间显示和音量。下一阶段会为“视频伴奏 + SWAM”的统一录音建立混音通道。

视频播放时会自动进入“演奏优先”模式：暂停非必要背景动画、降低画布与网页状态刷新频率，并减少 FFT 计算；原生伴奏通道扩大预读缓存且只在持续明显失步时校正位置，避免频繁跳转导致实时演奏断流。

演奏录音已接入原生程序：点击一次开始、再次点击停止并保存，自动生成 24-bit WAV 文件到用户“文档/风吟录音”目录。写盘在后台线程完成，不阻塞实时演奏。录音可同时写入内置测试音源或 VST3/SWAM 输出，以及风吟能够解码的伴奏音轨。

“录音文件”面板会按新到旧显示 WAV 名称、时长和文件大小，可打开录音文件夹；删除采用系统回收站，减少误操作造成的永久丢失。

选择视频后，风吟会先尝试直接读取其中的音轨，再寻找与视频同目录、同文件名的 WAV/MP3/FLAC；仍无法读取时，会在后台调用安装包自带的音轨提取组件，生成并复用缓存 WAV。用户始终只需选择一次视频。界面会明确显示“正在准备伴奏”“伴奏可录制”或“伴奏仅播放”。当前开发环境未放入 FFmpeg 可执行文件，正式 Windows 安装包需完成该组件的许可审查和打包。

永久激活已接入原生程序。用户只需把界面显示的本机码交给安装人员并粘贴一次激活码；验证和后续启动均不联网。正式应用只包含验证公钥，激活码生成私钥保存在被版本控制排除的 `private/` 目录，不会进入安装包。

店主端已提供独立的“风吟激活码工具”：粘贴客户本机码、填写订单编号、点击一次即可生成并复制永久激活码。Windows 构建脚本会把该工具和私钥单独整理到 `dist/店主激活工具/`，并在生成客户安装包前自动扫描，防止私钥误入客户目录。
