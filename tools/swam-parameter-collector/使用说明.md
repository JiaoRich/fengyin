# SWAM 全套参数采集器 2.0

适用于 Windows 64位，扫描已安装的SWAM VST3乐器。请提前完成插件安装和授权。支持实际安装的不同版本，逐一记录真实版本，不假设跨版本兼容。

1. 关闭风吟及其他使用SWAM的软件。
2. 完整解压，双击 `Start.cmd`。
3. 标准安装直接回车；有自定义VST3目录时输入Y，选择目录，可重复添加。
4. 工具按顺序显示进度，一个乐器失败不影响后续。全套需要几分钟，单个异常实例最多等待3分钟。
5. 将桌面生成的 `SWAM-Full-Collection-日期时间.zip` 整包发回，不必逐个导出。

## 内容和边界

采集全部公开参数的真实ID、当前/默认值、单位和归一化端点。非MIDI-CC代理参数通常采样1025点；低步数离散参数按公开步数查询。大量MIDI-CC代理只记录当前/默认、端点和中点，不作为音色设置。型号额外采样8193点，保存实际观察到的名称。中音、次中音额外查询已确认五套方案的精确目标值。

有限采样不证明曲线线性、不保证任意后续目标或所有枚举均覆盖。隐藏参数不包含在公开参数表中；插件升级或特殊目标仍可能需要补采。

独立实例只读查询，不发送MIDI、不打开声卡、不调用参数设置、状态恢复或保存接口。不修改风吟、既有音色、映射或驱动，无需管理员权限。插件自身初始化/授权行为由厂商实现，工具不绕过授权。

报告包含安装路径，请仅给可信支持人员。不包含插件本体、许可证、音色库或完整状态。执行策略参数仅影响本次PowerShell进程，不改变系统策略。

工具未购买Windows签名证书，若系统阻止运行请反馈提示，不要关闭杀毒软件。Windows编译、Mac功能测试、目标Windows实际采集、真人吹奏试听是不同验证层级，不混称通过。
