# SWAM Windows 参数采集器

这是独立工具，不安装、不修改风吟。适用 Windows 64位、已正常安装激活的 SWAM Alto Sax 3 和 SWAM Tenor Sax 3，版本3.9.4。

1. 关闭风吟和其他正在使用SWAM的软件。
2. 将工具ZIP完整解压，不要在压缩包里直接运行。
3. 双击 `Start.cmd`，按回车开始。通常无需管理员权限。
4. 默认查找此前确认的标准VST3路径；找不到时选择相应 `.vst3` 文件。
5. 完成后桌面生成 `SWAM-Parameter-Collection-日期时间.zip`，把整个ZIP发回即可。

查询在独立插件实例进行，只调用参数读取和显示值转换接口。不发送MIDI、不打开声卡、不调用参数设置、状态恢复或音色保存接口。插件自身的初始化/授权检查仍由插件厂商实现，本工具不绕过授权。

工具通过插件实际接口核对五套音色目标值。无法解析的值会记录为未解决，不猜测、不强行替代。两种音源分别运行，每个实例最多等两分钟；异常仅结束对应采集进程，保留错误日志。

报告包含插件安装路径、版本、型号名称与参数信息，不打包插件本体、许可证、现有音色库或完整插件状态。仅发给可信的技术支持。

`Start.cmd` 的执行策略参数只对本次PowerShell进程有效，不修改系统执行策略。工具尚未购买Windows签名证书；若系统安全策略阻止运行，请反馈提示，不要关闭杀毒软件。

重要：这是采集工具，不是音色方案包。Mac本机测试与Windows编译成功不等于目标Windows插件采集已验证；以运行后真实报告为准。
