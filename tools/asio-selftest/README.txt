风吟独立ASIO声音自检（仅诊断，不是驱动或修复安装包）

1. 关闭风吟、浏览器、微信和其他播放器，调低耳机/音箱音量。
2. 双击 FengYinAsioSelfTest.exe，阅读提示，点击确定。
3. 每次测试后选择“是”（听到）或“否”（没听到）。测试128帧和256帧，每次2秒。
4. 将桌面生成的“风吟独立ASIO自检-日期时间.txt”发回。

不需管理员权限，不修改系统默认输出，不安装或卸载驱动。
使用本机现有64位ASIO4ALL；没有可连接输出时不会播放，也会记录报告。
报告包含设备名、音频进程名称/PID及ASIO调用结果，不含录音和网页内容。
驱动异常或卡住时仅结束本工具的测试子进程；如果结果为失败，不要反复运行。
宿主之间的ASIO4ALL配置可能不同，对照成功不自动证明风吟代码是唯一原因。
Windows及杀毒软件可能提示此诊断工具未经签名；请核对来源，不要关闭系统防护。

技术说明：直接调用ASIO COM接口，不链接JUCE，无初始化试开输入，无虚拟音频混音。
