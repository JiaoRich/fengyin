风吟 WASAPI 共享周期检测工具

用途
直接读取 Windows IAudioClient3 返回的共享音频周期，确认声卡驱动是否真正支持 128、256 等低延迟缓冲。

使用方法
1. 首次检测前关闭风吟、浏览器、播放器等正在发声的软件。
2. 双击 FengYinWasapiPeriodProbe.exe，工具会自动检测所有可用输出设备。
3. 重点查看实际使用设备的 Default 和 RAW 两组结果。
4. 点击“复制结果”，把完整结果发给开发人员。
5. 可再打开浏览器播放声音后点击“重新检测”，判断音频引擎周期是否被其他程序锁定。

48 kHz 下的周期换算
128 samples = 2.67 ms
256 samples = 5.33 ms
480 samples = 10.00 ms
512 samples = 10.67 ms

说明
本工具不会安装驱动，不会修改 Windows 音频设置，也不会常驻后台。
