# 风吟安卓离线激活工具

仅供店主使用，不是客户安装的风吟演奏软件。支持 Android 8.0 及以上。

## 首次使用

1. 安装签名的 APK，按手机提示允许本次安装。
2. 手机须已设置锁屏密码、图案或 PIN。
3. 将电脑端使用的 `license-private-key.txt` 安全传到自己的手机，在本工具“设置 → 选择／更换激活私钥”中导入。
4. 验证锁屏身份后，私钥会加密保存在应用私有目录。确认导入成功后，可删除手机文件管理器中的明文副本（保留电脑上的安全备份）。

不要把私钥或本工具发给客户。安装包没有内置激活私钥，应用不申请网络权限。

## 日常激活

粘贴客户机器码 → 按需填写客户昵称、联系方式、订单来源、备注 → 生成、保存并复制 → 发给客户。

四项客户信息都可以留空，支持中文、符号和换行，不设置输入长度上限。机器码及内部授权编号遵循风吟许可协议的格式。

同一机器再次生成，会调出已有激活码，不重复创建记录。授权算法与电脑端一致，生成永久激活码。

## 记录

- 激活记录支持搜索、详情、复制、系统分享。
- CSV 导出供查看；为防止表格公式执行，特殊开头的文本会在 CSV 中加保护前缀，原始记录不改变。
- XML 备份保留完整记录，可导入本工具，也兼容电脑端记录 XML 格式。恢复按机器码去重，不覆盖已有客户资料。
- 手机与电脑没有自动同步。卸载、清除数据、换手机前必须导出 XML 备份；新手机重新导入私钥和记录即可。
- 密钥不进入系统云备份或记录备份。移除锁屏密码可能使密钥保护失效，需要重新导入原私钥。

## 开发与检查

JDK 17、Gradle 8.9、Android SDK 35；运行 `gradle testReleaseUnitTest lintRelease assembleRelease`。
发布构建需要独立的 APK 签名证书，通过 `FY_ANDROID_KEYSTORE` 和 `FY_ANDROID_SIGNING_PASSWORD` 提供。该证书不是风吟激活私钥。
GitHub Actions 构建并运行 Android 模拟器测试。测试使用临时测试 RSA 密钥，不使用生产激活私钥。
