# 风吟 0.11.1 低延迟修复验收清单

本版本只修复实时演奏链路，不加入“定制音色”等产品功能。

## 音频设备

- [x] Windows 默认只使用 WASAPI 共享低延迟；普通共享仅作兼容回退。
- [x] 使用设备实际公布的合法周期，不再把“请求 128”当成“实际 128”。
- [x] 自动模式从实际最小周期开始；不再按 CPU 核数或内存直接设为 256。
- [x] 共享模式优先匹配 Windows 当前混音采样率，避免隐藏重采样。
- [x] 运行中不得静默升到 512/1024；只提示用户在停止演奏后重新优化。
- [x] 演奏、录音或伴奏期间不得自动重启音频设备。

## 自动稳定性验证

- [x] 启动阶段只做设备能力选择，不把空载等待伪装成完整压力测试。
- [x] 音源加载后使用真实 VST3、内置音色链和音频回调做静音验证。
- [x] 记录实际周期、输出延迟、插件延迟、CPU 峰值和 xrun 增量。
- [x] 单次瞬时 xrun 不改变设置；持续异常只告警，不打断演奏。

## MIDI 实时路径

- [x] 保留 JUCE 输入消息原始时间戳。
- [x] MIDI 输入线程到音频线程使用预分配 SPSC 环形队列。
- [x] 音频线程把保留时间戳的消息交给 JUCE collector 生成块内 sample offset。
- [x] Note On/Off、弯音不抽稀；重复气息 CC 只去除完全相同的连续值。
- [x] MIDI 输入线程只写 SPSC 队列，不再跨线程调用 collector 与音频回调争锁。

## DSP 与界面隔离

- [x] 音色链参数按音频块读取，不在逐样本循环重复读取原子变量。
- [x] 音频线程不进行磁盘 IO、GUI 更新；MIDI 队列和 collector 容量在启动时预分配。
- [x] 伴奏保持预读并在同一输出回调混音。

## 诊断与发布门禁

- [x] 声音设置/运行状态输出实际驱动类型、采样率、周期、估算输出延迟、插件延迟、CPU、xrun 和 MIDI 丢失数。
- [x] 自动测试覆盖周期选择、禁止大缓冲升级、时间戳保留和队列溢出策略。
- [x] GitHub Windows 构建同时运行 CTest 与 Python 回归测试。
- [x] 上述测试全部通过后才能生成安装包。
