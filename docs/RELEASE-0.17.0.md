# 0.17.0 调音师工作台 — 实施与验收

实施范围：用户页简化；设置内 admin 入口（防误操作，不宣称安全授权）；多 VST3 串联；草稿隔离；音源完整状态/KAM/效果链/内置参数导出；插件依赖独立清单。不得自动捆绑个人授权、音源本体、采样库或未确认再分发权的插件。

已实现：
- 普通用户无制作、编辑删除、“我的方案”入口，风格加载及切换正常。
- 原生事件层检查调音师会话；退出关闭编辑器，草稿不进入用户列表。
- 多效果器增删、排序、旁通、打开原厂界面，串联顺序与声音链一致。
- 方案保存/重启还原包含每一实例的状态及顺序，缺失依赖明确报错，不能静默漏过。
- 调音师取消编辑能够恢复之前整套效果链。
- SWAM 完整状态与空音已有状态/KAM 路径保持，MIDI 适配不被风格加载覆盖。
- 导出包清单、状态文件、校验哈希完整；不含第三方二进制或授权。
- 包导出使用原子替换，失败不能显示成功。
- 本机编译、原生测试、UI桥接回归后才提交 Windows 构建。

插件包安装器：实际效果器名单及分发授权尚未选定，不伪造可安装插件。方案导出只生成准确依赖清单；后续以已确认插件制作独立安装包。

## 本机验证结果

- macOS Debug 完整构建通过。
- 17 项原生测试通过，包含新增的实际 AudioProcessorGraph 音频测试：先增益后偏置为 0.45，倒序为 0.70，旁路增益为 0.35，无效果为 0.10；左右声道均校验。
- 保存状态、修改连接不重新调用现有节点的 prepareToPlay/releaseResources，避免调音时破坏空音已加载的机架。此项由计数型测试处理器验证。
- 草稿、完整音源状态、多效果器状态/顺序/旁路、Air 等参数磁盘往返测试通过；异常编码和超出16项的效果链拒绝保存/读取。
- 方案包 ZIP 读取验证：tone.xml 能还原状态、manifest.json 依赖信息正确、SHA-256 一致、不包含插件本体；空音另附 KAM。
- 70 项 Python 回归通过。旧有“用户可以编辑/删除方案”结构断言更新为已批准的调音师隔离逻辑。
- 1366/1920 宽度的浏览器桥接测试通过：密码错误与成功、普通列表无草稿、效果器操作事件、Air 调整不被轮询覆盖、保存等待原生回执、导出先保存、草稿重开锁定音源。无 JS 运行错误。

## 必须在 Windows 实机复验（不以本机构建替代）

1. 设置 → 调音师入口 → admin，新建 SWAM 音色，打开原厂界面调参数。
2. 加入至少两款实际 VST3 效果器，分别打开编辑器、调参数、换序和旁路，确认听感与链路一致。
3. 保存草稿，退出并重开风吟，从草稿箱继续调音，确认源插件和所有效果器参数、顺序、旁路、Air 还原。
4. 空音选择二胡/笛子及奏法后保存；重启加载草稿，确认正常发声及奏法不变。
5. 取消修改、退出调音师，确认返回之前音色及效果链；普通音色页没有草稿与编辑删除入口。
6. 导出 .fytonepack 发回，核对原厂插件版本及资源依赖。第三方插件可能引用外部 IR/用户预设等资源，包内状态不是这些资源的安装文件，定稿前需要逐插件验证和归档。
7. 缺失第三方效果器或版本不一致应报错，不能无提示地播放残缺效果。

边界：本机没有这一组 Windows 商业插件，尚不能声称所有厂商插件已通过发声、状态恢复和授权验证。调音包目前供汇总纳入正式预设，不向普通用户开放导入；独立插件包待清单与授权确定后制作。admin 仅为防误操作入口，不是安全隔离或付费权限。
