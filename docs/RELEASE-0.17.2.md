# 0.17.2 — 方案包恢复安全修复

## 证据与边界

用户的“中音萨克斯-雨蝶”包校验通过，来源 SWAM 3.8.2，32 个参数，无完整插件状态、无第三方效果器。Windows 报告 SWAM Alto Sax 3.9.4 内部访问异常 c0000005，日志最后为 Plugin graph ready。没有崩溃堆栈，不能证明具体致错指令。

## 修改

- 新图交给播放器前暂停，初始化回调完成后才恢复；恢复时核对生命周期和加载代次。
- 批量音色参数、型号、SWAM 表情状态修改使用 ScopedGraphPause，不 release/prepare 插件，不改变空音恢复协议。
- 型号名称随草稿、方案包保存并优先精确匹配。旧包跨版本仅有型号序号时不猜测型号，显示提示。
- 不向不同版本 SWAM 写入未经验证的完整二进制状态；明确报告版本不一致。
- 参数仍按原有序号加名称 / 稳定 ID 精确匹配，未匹配不写入并报告数量。尚未实现经过实测的跨版本参数语义转换。
- 导入成功提示保留恢复警告；增加加载阶段日志。

## 验收

- 本机构建、CTest、Python 回归和 1366/1920 调音师界面测试。
- 型号名称包往返、嵌套暂停状态、初始化暂停先于播放器暴露的回归。
- Windows 必测：3.9.4 导入用户包不退出；显示旧型号缺失提示；打开原厂界面确认型号并试听；保存草稿后重启再加载。
- Windows 必测：同版本完整 SWAM 状态、第三方效果链、空音方案切换与发声。

本机自动检查不能替代 Windows SWAM 3.9.4 插件实测；发布为修复候选，不宣称用户闪退已复现或完全消除。
