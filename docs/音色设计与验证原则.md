# 音色设计与验证原则

用户确认：后续风格设计不能局限于 SwamToneProfile 现有 9 类参数。应根据目标风格联合调整乐器型号、音色结构、起音、噪声及其他实际需要的音源参数和风吟效果链。

- 先获取真实插件的参数 ID、名称、显示值、范围和完整状态，不凭英文名称猜测参数已生效。
- 保留 MIDI 路由、气息智能适配、用户硬件技巧映射。任何涉及表情曲线、技巧参数的风格设计必须明确其与全局控制的优先级，不能静默覆盖用户设置。
- 新风格必须逐项读回核对，并用相同型号、MIDI 演奏、音区、气息比较干声与加效果链的音频。参数不同不能代替听感验收。
- 本次仅增加参数诊断，不改变现有默认风格、SWAM 参数或空音链路。

## 0.16.10 参数导出验收

- 软件设置提供“导出当前音色参数”；未加载 SWAM、加载中时禁用。
- 默认方案、自定义方案都可导出，无需进入编辑页面。
- 读取当前实例，不重新加载，不重置，不应用风格，不写入任何插件参数。
- 导出所有宿主公开参数（包括 MIDI、型号和技巧）、ID、原名、中文译名、归一化值、显示值、单位、默认值。
- 尚无可靠译名时保留原名，明确标为待核对；不能声称有限词典覆盖所有版本。
- 原始插件状态按标准 Base64 无损保存；记录插件版本、当前风格和风吟效果链。隐藏参数可能仅在原始状态中，不能冒充均已解析。
- 保存取消、无写入权限、空状态均给出实际结果。重复点击不重复打开保存窗口。
- 状态抓取在消息线程进行；提醒停止吹奏，并禁止在录音中抓取，避免读状态时短暂阻塞回调影响录音。
- 文件仅由用户保存，不上传。提示完整状态可能带有本地路径等插件信息。
- 自动测试验证全量枚举、MIDI 项不被过滤、未知译名、二进制零字节往返、空状态、抓取前后参数不变。
- Windows SWAM 的真实参数及发声不变验证仍需在装有对应插件的电脑完成；模拟处理器测试不是实插件验收。
