# 1.0.4 KoordASIO 共享低延迟测试版

本版替换已经证明不稳定的 SAR 动态桥接方案。KoordASIO 使用 WASAPI Shared，风吟与浏览器、微信及播放器直接由 Windows 混音，不创建虚拟播放端点，也不要求管理员权限。

## 安全边界

- 风吟只识别并打开 `KoordASIO`，不会打开 ASIO4ALL、SAR 或其他 ASIO 驱动。
- 升级后自动废弃旧 SAR 保存状态，首次启动回到稳定的 Windows 共享输出。
- 自动优化不会擅自进入 KoordASIO；只有用户在声音设置中主动选择才启用。
- KoordASIO 仅打开输出，关闭麦克风和其他输入，降低调度压力。
- 切换缓冲区失败时恢复上一个可用值，不重复切换驱动类型。

## 测试步骤

1. 卸载 Synchronous Audio Router；ASIO4ALL 可以保留，但本版不会调用它。
2. 从 KoordASIO 官方发布页安装当前签名版本：
   <https://github.com/kormix-io/KoordASIO/releases>
3. 正常启动风吟，不需要管理员权限。
4. 在声音设置中选择“共享低延迟测试（KoordASIO）”。
5. 保持 Windows 默认输出为正在使用的扬声器或耳机；浏览器无需修改输出设备。
6. 先用 256 缓冲确认稳定，再尝试 128；如果出现爆音就恢复 256。
7. 同时播放网页视频并吹奏，记录风吟显示延迟、听感延迟、爆音和其他应用是否正常发声。

## 验收重点

- 风吟能够重复启动和退出，Windows 可以正常关机、重启。
- 浏览器与风吟同时从相同耳机或扬声器发声。
- 插拔耳机后 KoordASIO 能跟随 Windows 默认输出。
- 修改缓冲区后风吟不会卡死；不支持的值会恢复原设置。
- 未选择 KoordASIO 时，风吟原有 Windows 共享模式完全不受影响。
