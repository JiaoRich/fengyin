# 风吟 0.16.0 超级低延迟优化验收清单

## 实现范围

- 声音设置增加“超级低延迟优化”入口，与原有无风险的“智能优化”分开。
- 仅在 Windows 检测到单一 Realtek、Senary 或 C-Media HDA 板载声卡时允许执行。
- 执行前必须阅读风险并勾选确认；随后由 Windows UAC 请求管理员权限。
- 删除 OEM 驱动包前，先用 `pnputil /export-driver` 完整备份驱动并保存设备、版本和电源计划信息。
- 备份成功后才解绑 OEM 驱动，让 Windows 绑定系统自带的 `hdaudio.inf`；绑定失败会立即尝试回滚。
- 优化同时切换高性能电源计划；恢复原驱动时一并恢复原电源计划。
- 驱动变化和重启后，仍由风吟原有智能音频优化重新识别共享输出、采样率和可稳定的最低缓冲区。
- 不下载、安装或运行视频中提到的未知第三方降延迟工具。

## 本机自验

- [ ] CMake 完整编译通过。
- [ ] Python 回归测试全部通过。
- [ ] Playwright UI 测试验证风险弹窗、必选勾选和取消流程。
- [ ] 脚本中驱动备份操作的顺序早于驱动删除操作。
- [ ] 代码不包含远程下载或自动安装第三方驱动的逻辑。

## Windows 实机验收

- [ ] 已使用微软通用 HDA 驱动的电脑不会重复修改驱动。
- [ ] 无符合条件的声卡或存在多个候选设备时，不更改系统。
- [ ] 检测到 Dolby/Nahimic/A-Volute 服务时中止并给出中文说明。
- [ ] 拒绝 UAC 后显示未更改系统，软件可继续使用。
- [ ] 备份失败时不解绑当前驱动。
- [ ] 优化成功后提示重启，重启后智能音频优化重新测量并保存最稳定的低延迟设置。
- [ ] 软音源、伴奏视频和其他 Windows 应用可同时从同一输出设备发声。
- [ ] “恢复原驱动”能从本地备份恢复 OEM 驱动和原电源计划。
