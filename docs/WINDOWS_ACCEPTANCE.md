# Windows 真机验收单

这份清单用于第一台 Windows 测试机。每项只需填写“通过 / 不通过 / 备注”，不要求使用者懂开发。

## 测试前准备

- Windows 10/11 64 位电脑一台
- 已授权的 SWAM VST3 音源至少一个
- 电吹管一支及其 USB MIDI 连接线
- 声卡与 ASIO 驱动；没有独立声卡时可先用系统输出
- MP4 视频一个、耳机或音箱

## 安装与激活

- 中文安装向导可正常完成安装
- 桌面或开始菜单“风吟”可以启动
- 界面中文字无乱码、按钮没有被截断
- 能复制本机码，店主工具能生成激活码
- 激活后重启仍显示“永久版”
- 卸载再安装后，激活状态和个人数据仍保留

## 电吹管与声音

- 软件能列出并连接电吹管
- 每次重新连接后，界面提示“请吹 C 指法”；吹一次后能正确显示识别出的吹管本调
- 吹管设为降 E、软件“演奏调”设为 A 时，C 指法实际发出 A 音；再用 C 调和降 B 调各复测一次
- 长音识别能正确判断 CC2 / CC11 等气息控制
- 音符、气息、弯音均有响应，无明显卡音
- 能选择 ASIO 驱动、输出通道、采样率和缓冲区
- 128 或 256 缓冲下连续吹奏 20 分钟无爆音、崩溃

## SWAM 与效果器

- 扫描能找到已安装的 SWAM VST3
- 加载后能够正常发声并响应气息强弱
- 插件原始界面可以打开和关闭
- 能加载一个 VST3 效果器，旁通和移除均正常
- 保存音色方案后重启，音源、效果器和参数能恢复

## 视频、显示与录音

- MP4 可播放、暂停、拖动进度和调节音量
- 电平、频谱和彩色跑马灯跟随真实声音变化
- 分别用 1080p H.264/AAC 视频播放 10 分钟：持续吹奏不丢音、不卡音、无明显爆音
- 视频播放时切换主题、全屏、拖动进度后继续吹奏，声音仍稳定
- 录音 WAV 同时包含吹奏和伴奏，播放无失真
- 录音列表能显示、打开文件夹并移入回收站

## 异常恢复

- 未连接电吹管时提示清楚，软件不会卡死
- 插件加载失败后可回到测试音源继续操作
- 声卡被拔出后能给出中文提示或恢复到可用设备
- 强制关闭再启动，不会留下无法播放的半成品录音

## 通过标准

安装、激活、连续吹奏、SWAM、视频混录五项必须全部通过。其他问题按“阻断发布 / 可以后补 / 仅外观”三级记录，修复后再生成首个对外测试包。
