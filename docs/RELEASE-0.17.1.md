# 0.17.1 — 调音师整套方案导入

入口：软件设置 → 调音师入口（admin）→ 导入方案包。

- 读取 0.17.0 导出的 `.fytonepack`，恢复音源完整状态/参数、空音 KAM、第三方效果器顺序/状态/旁路和风吟效果参数。
- 每次导入创建新的草稿 ID；同乐器同名草稿增加“导入 n”后缀，不覆盖原草稿或系统方案。
- 使用现有插件扫描结果按身份匹配，不要求另一台电脑的插件路径相同。不安装或执行包内文件。
- 成功加载后直接打开调音编辑器，允许修改风格名、打开原厂界面、调效果链、保存草稿和再次导出。
- 缺少插件/效果器版本不一致时，草稿保留在草稿箱并持续显示错误；不会宣称完整加载。
- 校验包格式、版本、文件清单、大小与 SHA-256。禁止目录路径、重复文件、额外文件及超限解压；拒绝异常参数与缺失/不一致的 KAM。
- 只有激活且已进入调音师会话才能调用导入，普通用户页面不提供导入入口。

验收：
1. 原生测试：SWAM 和空音包导出→导入，状态字节与效果器参数一致；重复导入 ID 不同；损坏包、路径穿越、重复文件拒绝。
2. UI 桥接：导入按钮发送原生事件；错误信息可见；缺少插件转草稿箱；加载成功进入编辑并能保存。
3. 本机完整构建、全部原生测试、Python 回归、1366/1920 界面测试后提交 Windows 构建。
4. Windows 实机仍需检验实际商业插件的发声和完整状态还原。方案包不含插件安装文件、授权或采样库，需要本机已安装相应资源。

本机结果：完整构建通过，17 项原生测试、70 项 Python 回归通过；1366/1920 宽度的界面桥接测试通过。新增断言涵盖导入后正确显示并锁定原音源，防止沿用上一次选择的下拉值。
