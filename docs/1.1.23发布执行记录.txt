风吟 1.1.23：LibVLC 伴奏播放与小提琴内部房间开关

授权与边界
用户用外部 VLC + 风吟大提琴验证流畅，明确授权内置 VLC 并关闭小提琴房间混响。
此前暂停的广泛性能排查不再作为自动修改依据；这版只替换 Windows 伴奏链路、关闭柔美小提琴内部房间，并保留已完成的默认关闭诊断观察点。
不更改默认128缓冲、用户设备路由、电源、驱动、ASIO/VB-CABLE、增益、气息、弯音、音高、颤音或抖弓。录屏保留1080P24 H2648M/AAC192k，录音保留系统输出48k PCM。

播放架构
VideoLAN 官方 VideoLAN.LibVLC.Windows 3.0.24 LGPL 发行包，非 Windows.GPL 包。
固定 NuGet SHA256 3da3f37ee2b2b10e5c788d830a3b513658c36521ea1b0f966ed86eb69f41ef3c。
动态加载应用私有 components/VLC/libvlc.dll、libvlccore.dll，独立工作线程负责媒体初始化、加载、播放/暂停、跳转、换片与释放；不在吹奏回调中调用 VLC。
LibVLC 同时处理原文件的声音和画面，使用其原生 HWND 视频输出与自动硬件解码选择；不做 CPU 帧回调，不保证所有编码/设备都能硬解。
Windows 不再调用 WAV 提取、空闲视频代理转码、网页视频解码或音频时钟追帧。只是读取本地媒体元数据，不通过自动播放取得预览；点击播放前画面区域为黑底。
伴奏通过 VLC 常规系统音频输出，风吟系统 loopback 录音/录屏继续收集实际系统输出。没有把 VLC PCM 塞回乐器实时回调。目标机必须复核实际扬声器端点、伴奏音量、录制是否包含二者，不把 CI 的 PCM 测试当扬声器验收。
非 Windows 开发路径保留原播放器，不宣称已实现或验证 Mac LibVLC。
命令为最新值有界邮箱，媒体 generation、seek revision 与播放命令检查阻止旧状态覆盖。换片先释放旧媒体；退出泵送原生同步消息，避免 VLC 渲染器关闭时等 HWND 线程死锁。不会强杀线程。
网页只显示状态和提交显式操作；控件与原生画面分行布局。切页/最小化/对话框/菜单/音色快捷面板隐藏原生画面，不由网页暂停第二解码器。切精简沿用原先提示与暂停行为。
FFmpeg 仍随包保留给既有编码检查及旧路径，不再用于 Windows 伴奏预处理。
