下一版本录制与界面调整方案
记录日期：2026-10-21
基线：1.1.27 / Windows 构建 236。2026-10-21用户确认以上方案开始执行，目标版本1.1.28；完成状态以文末执行记录及实际构建结果为准。

一、已确认的录制交互
1. 单一主按钮“开始录制”，移除旁边的类型下拉箭头。点击按钮展开“录音 / 录屏”选择，选中后直接进入准备流程，不再弹开始确认对话框。
2. 用户选中录音 / 录屏的瞬间，并行开始后台组件准备和语音提示“准备录音 / 录屏，将在滴声后开始”。不得等语音播放结束再准备；不再使用321或固定3秒作为就绪依据。
3. 组件就绪且语音提示已播放结束后，播放一次滴声；滴声结束才正式采集并显示“正在录制”。准备期间不计入成片，语音、滴声不进入成片；就绪失败显示原因，不假装已经录制。具体采集起点须通过音频时间戳/首帧测试验证，不能仅靠界面延时。
4. 准备中提供取消；正在录制时主按钮明确支持停止（“正在录制 · 停止”或等价明确交互），避免用户不知道如何停止。录制中不允许切换类型或重复启动。
5. 用户停止后自动生成最终文件，删除手动“生成视频”步骤及其确认框。按钮转圈，文字“正在保存，请稍等”，保存阶段禁止重复启动。
6. 保存期间暂时禁用吹奏：先正常停音并清理相关音符状态，再阻止演奏输入触发音源，避免挂音；保存成功、失败及取消/退出异常路径均恢复可用状态，不修改现有调音参数。伴奏不强制暂停。重型保存工作仍在独立低优先级进程，禁止阻塞音频回调或UI线程。
7. 保存并验证成功后文字条提示“录制成功！在这里查看录屏文件”，小箭头指向“我的录制”；录音对应提示录音文件。失败显示真实原因而非成功提示。
8. 全屏和精简模式继续录制开始时风吟所在整块显示器。任务栏排除不是必须项，不能为了排除增加不必要开销。维持硬件编码检查，无CPU软件编码静默降级。

二、录制目录与清理（已确认）
风吟录制/
  录音文件/    仅完成的WAV
  录屏文件/    仅完成的MP4
  临时文件/    每次会话独立目录：原始音视频、状态、诊断、失败输出
1. 临时资料不存风吟安装/程序内部目录，均放上述“临时文件”。正式录屏目录不得出现状态、WAV、原始视频或会话子目录。
2. 最终文件写完并验证成功后，自动清理本次会话临时文件；只清理该次录制所有的目录，禁止删除其他录制或任意用户文件。
3. 保存失败或异常退出时保留可恢复资料，不为了清空目录毁掉唯一素材；后续进入录制管理提供恢复/清理入口。不得无提示无限积压；具体残留保留策略实现时说明。

三、按钮规格与演奏页分组
1. “开始录制”“我的录制”相同高度、相同字号、相同按钮规格；使用主色填充/次级描边突出录制，不依赖不同尺寸。
2. 保持现有底栏顺序及一行布局，仅适当增加以下三组之间的空隙：
   录制组：[开始录制] [我的录制]
   乐曲速度组：[慢速] [中速] [快速]
   音高组：[演奏调] [弯音]
3. 组内间距较小，三组间距以18px作为原型参考，不扩展为重新设计底栏，不新增上下分层的组标题。
4. 混响、吹奏音量、主题保持与以上控件同一行，不另起一行、不新增分隔横线，不改其值或调音行为。此前原型“独立次行”的安排作废。
5. 精简模式现有按钮布局保持不变，不改变顺序、位置、行数和原有布局规则；不能将普通模式的原型响应式排版套进精简模式。但录制按钮、类型选择、准备/滴声、停止/自动保存、结果提示与普通模式同步更新（用户后续明确提醒）。只在普通模式三组之间微调间距，两模式统一两录制按钮规格。
6. 原型已确认，正在修改正式程序，不追加其他界面重设计。

四、高级设置合并（布局已确认）
1. 侧栏“声音设置”“软件设置”合并为“高级设置”。主要信息为“声音输出 / 授权与激活”；播报开关和调音师入口独立放置，不共用分类标题或外框。
2. 保留声音模式、输出设备、采样率、缓冲区、预计延迟。删除“智能优化”按钮及其专属调用/功能链；不误删必要的设备初始化、格式兼容性检查及已验证性能修复。
3. 保留激活状态、本机识别码和复制入口；未激活时显示激活码输入框与激活按钮，已激活时隐藏输入/激活操作。保持真实授权校验，不由原型状态决定授权。
4. 删除低性能电脑模式、启动时进入演奏页面、自动保存设置、检查软件更新四个按钮。删除低性能模式专属UI/可切换行为时保留已验证的默认性能策略；删除自动保存“开关”不等于禁用必要的设置持久化。
5. 保留调音师入口、语音提示、音色播报、软件版本。语音提示和音色播报独立可调。继承用户现有偏好：语音提示关闭时跳过准备播报，仍保留滴声作为正式开始的必要提示；音色播报开关不影响录制起点。
6. 高级设置默认双栏：声音输出在左，授权在右；下方左侧直接放语音提示、音色播报两个开关，下方右侧独立放调音师入口，去掉“使用偏好与调音师”标题及共用外框。软件版本独立在右下方。未激活状态也尽量一屏容纳；窄屏自然改为单栏，禁止为硬凑一屏缩小文字/触摸目标。
7. 已按确认布局实施；不触及音色、增益、气息曲线、CC映射、DSP、路由、默认128缓冲、驱动或电源方案。

五、实施与验收顺序
先确认原型 → 调整正式交互与后台状态机 → 自动保存与临时目录迁移 → 删除/合并设置专属链路 → 自动回归 → Windows完整构建 → 原机体验验收。
验收覆盖：两种录制的准备并行/取消/失败/提示音排除、停止自动保存、保存失败恢复吹奏、无挂音、正式目录仅最终文件、临时清理边界、窄屏触摸、未激活/已激活、设备设置持久化与既有性能回归。
