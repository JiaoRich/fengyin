风吟：音色直出、独立音量与移调（2026-10-12）

本次范围
1. 原主音量改为吹奏音量，放在乐器效果处理之后、伴奏混合之前。视频伴奏沿用自己的音量，不再跟随吹奏音量。
2. 移除固定吹奏增益、伴奏衰减、低频滤除、隐藏总线保护/硬削波和乐器类别混响修饰。过载仅记录，不自动降音量。整数声卡格式的数值范围转换仍必须保留。
   空音不再强制把输入力度改为96/127，改用电吹管原始力度；空音首次起音力度需重点真机回归，本机没有对应插件，未声称已实测。
3. 保留音源、外部效果器以及显式风吟效果链。JUCE 混响干声参数按其内部两倍系数修正；零混响直接旁通。
4. 取消风吟统一气息曲线和技巧强度/门槛计算，保留智能适配中的用户技巧映射。已有原厂 MIDI 曲线通过原厂 CC 路由，不再用参数直写覆盖；未配置原厂 MIDI 曲线的技巧维持原值参数控制，不猜测曲线或参数索引。
5. 既有曲线视为方案的一部分，原样保留；可解析 XML 中缺少表情曲线时补线性。不能仅凭曲线数值断定它是原厂值还是调音师自定义，不擅自覆盖。未知二进制外壳只读取，不猜写长度/校验字段。
6. 两个保存入口均保存完整音源状态、外部效果链和全部风吟效果参数。保存时不重新套用可能过期的网页快照；完整状态加载后不再重复选型号、覆写旧参数列表。
7. 移调改为一级减号、带符号半音值、加号，范围 -12 至 +12；0跟随电吹管。不再要求管子设成C调。升级默认0，之后记忆用户选择。已按下音符继续按原音高结束，新音符使用新偏移。
8. 新用户不自动开启技巧；已有用户映射保留。保持已批准的 SWAM Attack Control=Expression 策略，后续新包仍须按 AGENTS.md 检查确认。

不在本次范围
ASIO、Realtek端点、驱动、VB-CABLE路由、安装流程均未修改（安装包版本号升至1.1.9）。未引入三档气息曲线或 CUDA。
网页外部伴奏仍由网页/Windows原有控制；风吟的伴奏音量控件控制风吟载入的视频，不声称能统一控制所有第三方程序。

交付前仍需区分
上述不是 Windows 故障机实际演奏验收，也不代表 Windows 安装包已经生成。
取消保护后用户可将输出推到削波；取消固定增益/衰减与干声倍增后，原来方案的响度会变化，需要由调音师重新平衡。
旧技巧自动阈值不再生效，启用气息映射后其响应以方案曲线为准；没有原厂映射曲线时是原值控制。
引导的C调要求已删除，旧的C调语音不再播放；新增26段移调离线语音（Tingting中文，与原Xiaoxiao音色不同），覆盖引导、零移调及升降1—12半音。音频需通过非空PCM回归检查。
复核补充：音源卸载和原生曲线重读时清空旧CC路由及通道，防止上一个音源的映射残留；移调偏好所有保存路径统一写入transposeOffsetV2。
