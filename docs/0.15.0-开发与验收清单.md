## 空音适配

已写入代码：

- 扫描放到独立子进程；45 秒超时终止、取消扫描检查、异常输出不接收。
- 扫描空音时创建独立实例读取宿主可见的 programs，不占用当前演奏实例。
- 插件与 program 名称、索引独立缓存，不再从当前演奏插件临时拼列表。
- 列表绑定扫描到的插件 ID 与准确 program 名；找不到 program 返回失败，不再弹原厂界面后报成功。
- 选择 program 时先脱离音频回调，避免在实时处理同时载入采样。
- 第一次进入空音分组时，若已扫描到 QinEngineV3 但未定位音色库，会直接请用户选择包含 `.KAI` 的目录；路径支持中文、空格和非系统盘，选择成功后记住。
- 已按用户实际音色库补齐常见 KAI 拼音名的中文映射，包括二胡、板胡、编磬、编钟、柯克交响系列等；保留 `23/65` 等型号后缀。
- 新增 12 张统一风格、透明背景的常见民乐图片，已覆盖二胡、古筝、笛子、琵琶、唢呐、葫芦丝、扬琴、古琴、笙、中阮、箫和板胡；其他相近乐器复用同系图片。空音演奏卡不显示 SWAM 专用的“乐器型号”切换框。
- SWAM 提琴已区分“独奏”和“重奏”的中文名称及内部键，避免 Violin/Cello Section 与独奏版同名。
- SWAM 型号选择兼容 VST3 将 Instrument/Instrument Body 以连续参数暴露的情况：从宿主可见文本中枚举真实型号，保存对应的归一化参数值，不再依赖等距假设。
- 支持自选 VST3 文件夹、保存扫描路径、补充 Windows 用户级 VST3 路径。
- 增加中文厂商与完整中文乐器名识别。
- 新增空音音色库路径定位：支持读取明文 XML `KAIFolderPath`、用户一次选择后持久保存、当前用户默认文档音色库目录。非明文配置不破解、不推断；不扫描全盘、不写死用户 D 盘路径。明确配置或已保存路径失效时不会悄悄切换另一目录。
- 只统计所选目录直接包含的 `.KAI` 文件，扩展名不区分大小写；最多检查 4096 个文件，不读取采样内容。该清单不等同于乐器内部 ID，也不据此创建假可用卡片。
- 音色方案空音分组增加“选择/更换音色库目录”，与 VST3 插件目录选择分开。选择只保存到风吟，不改动 Qin 原厂配置；因此要求与 Qin 设置中的目录一致。

尚未完成，不能宣称“完整支持”的项目：

1. 已确认用户报告版本 3.11，路径为 `C:\Program Files\Common Files\VST3\Kong Audio\QinEngineV3.vst3`。仍需该 Windows 版本实际运行验证。
2. 已从官网下载并只解包 Mac 3.17.2 插件到临时目录（没有系统安装）。独立扫描创建实例成功，返回 `programCount=0`，17 个立体声输出总线、34 个输出通道。参数中包含 `KAI_ID_0`、`Preset_ID_0`、`Midi_0`、`Audio_0` 等。当前环境没有授权音色库，因此不能把此结果等同于用户 3.11 已安装库的完整行为。自动列表不能只靠 getNumPrograms；内部乐器 ID 与名称、已安装库的对应关系仍待验证。
3. 逐乐器验证音符、气息控制器、持续音与弹拨音起音方式；原有 CC1 路由尚未获得真实验证。
4. 真实音色库加载、授权失败、缺采样、Windows 子进程异常退出及超时测试。
5. 已实现空音专用完整状态保存、读回、载入及取消定制时恢复，限制最大 16 MB。参数/状态修改脱离实时回调；SWAM 不保存或恢复该状态块，仍使用参数快照。原生 setStateInformation 无成功返回值，连接建立不代表采样授权与实际发声成功，仍需真实乐器试听验证。已保存空音方案在没有 program 清单时也会显示，不伪造默认乐器方案。
6. 相同空音乐器来自多个插件/音色库时的去重与选择规则需要真实样本验证。
