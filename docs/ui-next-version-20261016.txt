下一版本UI需求（2026-10-16，用户已确认保留当前原型方案，下一版本实施）
1. 全屏音色方案页缩小卡片，优先在1366×768、1280×720等常用可用分辨率一屏展示当前32套内置音色；保留可读字号和拖动排序；不再显示/绘制音色卡片动态电平图。
2. 主题统一覆盖整体背景、左侧菜单、顶部、视频区域、内容面板、弹窗及控件，不再残留默认蓝色底。
3. 开始录音、我的录音、慢速/中速/快速、演奏调、弯音、主题统一高度、圆角、边框、字体、选中和悬停状态，全屏与精简模式采用同一套样式。
4. 音色页只有卡片容器滚动，页面标题、音色列表标题和底部操作栏固定；较小窗口或方案增多时不带动整页滚动。
5. 主题、弯音范围等简单选择采用按钮上方展开的就地菜单，点击外部或Escape收起；不使用遮罩弹窗。需要提示C调的演奏调仍保留原有弹窗。
6. 音色方案页不显示底部演奏操作栏；录音、演奏调、弯音、速度等仅在演奏页及其精简模式显示。
本轮只制作独立网页原型供用户确认，不修改正式音频/MIDI处理、不提交安装包构建。
原型内数据和操作均为界面演示，不连接音源、不实际录音。
