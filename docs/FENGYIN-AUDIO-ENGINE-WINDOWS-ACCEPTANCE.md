# 风吟音频引擎 Windows 实机验收

## 发布前提

- `driver` 目录必须来自微软 Hardware Dev Center 返回包，不能使用 CI 的 WDK 测试签名产物。
- 测试电脑必须先创建系统还原点并保存重要工作；不允许开启 Windows 测试模式。
- 至少覆盖 Windows 10 22H2、Windows 11、Realtek 笔记本、带 Dolby/Nahimic 的电脑和一台 USB 声卡。

## 自动冒烟验收

以管理员 PowerShell 运行：

```powershell
./scripts/test-audio-engine-install.ps1 -PackageDir "C:\风吟测试包"
```

脚本依次验证驱动安装、固定硬件 ID、独立引擎启动、强制结束后的默认输出恢复及测试驱动卸载。通过只代表安装事务和异常恢复基本正常，不替代听感与延迟测试。

## 必须逐项人工验收

1. 全新安装一次、覆盖升级一次、卸载一次；每次检查默认扬声器均正确恢复。
2. 连续启动/退出 50 次，任务管理器无残留引擎或看门狗进程。
3. 浏览器视频、微信语音和风吟同时发声 60 分钟；网页保持原声，乐器无爆音、丢音、左右声道缺失。
4. 分别测试 128、256、512；记录软件显示的实际缓冲和实测端到端延迟。128 不稳时应自动回退，不能卡死或退出。
5. 演奏中插拔耳机/音响各 30 次；只允许短暂淡出淡入，不重载 SWAM/空音，不重新跑智能优化。
6. 休眠/唤醒 20 次，Windows Audio 服务重启 10 次；引擎恢复失败时必须回退共享模式并恢复系统声音。
7. 分别强制结束 FengYin.exe、FengYinAudioEngine.exe；网页和默认输出必须自动恢复。
8. 逐项回归 SWAM、空音、预置音色、气息、硬件技巧映射、弯音、移调、视频导入/更换/暂停/定位和录音。
9. 正常重启和关机各 20 次；不允许出现无法启动、无法重启或必须断电。
10. 导出诊断包，确认不包含音频内容、激活私钥、客户资料或音色方案。

## 通过标准

- 目标演奏端到端延迟 6–12 ms；以实测为准，不使用缓冲公式冒充测量结果。
- 任何失败都不能破坏厂商声卡驱动、系统默认输出或其他应用声音。
- 只有上述矩阵全部通过的安装包才允许标记为公开测试版。
