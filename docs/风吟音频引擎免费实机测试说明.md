# 风吟音频引擎免费实机测试说明

这不是客户正式版。它只用于在购买正式驱动签名前，验证风吟自研音频引擎是否真的能降低延迟并保持 Windows 其他软件同时发声。

## 测试前

- 使用备用的实体 Windows 10/11 电脑；虚拟机只能验证安装，不能验证真实延迟。
- 创建 Windows 还原点，保存重要资料。
- 如果电脑启用了 BitLocker，先保存恢复密钥。需要关闭安全启动时，应先暂停 BitLocker。
- 记录当前风吟共享模式的驱动、采样率、缓冲区、显示延迟和实际吹奏感受，作为对照。

## 安装顺序

1. 双击 `1-开启测试模式.cmd`，同意管理员授权并按提示重启。
2. 重启后双击 `2-安装测试音频引擎.cmd`。
3. 直接运行本目录的 `FengYin.exe`。检测到测试驱动后，风吟会优先启用独立音频引擎。

风吟不会自动关闭安全启动、暂停 BitLocker或重启电脑，也不会把测试证书装进正式客户安装包。

## 必测项目

按同一台电脑、同一个 SWAM 音色、同一副耳机进行 A/B 对照：

1. 连续吹奏 10 分钟，记录主观延迟、显示缓冲区和显示延迟。
2. 浏览器播放动态谱或视频，同时吹奏，确认双方都有声音。
3. 快速吐音、连奏、强弱气息和弯音，检查丢音、爆音、卡顿和节奏漂移。
4. 插入、拔出耳机各三次，确认输出正确切换且没有持续咔哒声。
5. 正常退出风吟后再次启动三次，确认均能启动。
6. 风吟运行时强制结束进程一次，确认系统声音能被恢复。
7. 正常重启和关机各一次，确认不会卡住。
8. 伴奏视频、录音、音色方案、技巧映射和激活状态各验证一次。

只有实体机上的端到端吹奏体验明显优于共享模式，且上述稳定性项目全部通过，才值得进入正式签名和公开发布阶段。

## 完整回滚

1. 双击 `3-卸载并恢复系统声音.cmd`。
2. 再双击 `4-关闭测试模式.cmd` 并重启。
3. 如果测试前手动关闭过安全启动，在确认 Windows 正常后自行重新开启。

卸载脚本会先恢复 Windows 默认输出，再删除虚拟驱动和本测试包的确切证书；任何一步不能确认安全恢复时都会停止，而不是继续删除。
