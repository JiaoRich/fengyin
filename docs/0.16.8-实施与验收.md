# 0.16.8 实施与验收

## 本次范围

- 执行驱动脚本误拦截修复、硬件机器码改造。
- 演奏调右侧新增弯音按钮：±1、±2、±3、±4。西洋默认±1，民乐默认±3。
- 加载乐器后显示推荐提示；用户确认后按乐器记住范围；恢复推荐值会移除覆盖值。
- 修正插件切换中发现的生命周期/并发风险，空音恢复不再注入重拼的 KAM 状态。
- 不修改其他应用耳机输出，不开发支付、分销。

## 弯音实现

通过音源实际暴露的 Pitch Bend Up/Down 参数及文本转换设置，不缩放 MIDI 来伪装半音数，不改气息映射。先查到两端合法值再一起写入、回读检查；失败不保存偏好且界面不显示已成功。

用户提供的空音3.11诊断显示：PitchbendUp 值0.833333对应显示2，PitchbendDown值0.166667对应显示-2，两者均13档。新测试覆盖这种反向选项编码，不能直接把值3写入归一化参数。

偏好保存在 FengYin/bend-ranges.json，以插件标识+乐器标识区分。弹窗打开后换乐器会关闭，后端再次验证乐器标识。自定义方案参数恢复后重应用此偏好，避免音色参数覆盖弯音选择。未暴露可靠范围参数的音源明确报告失败，不猜测状态字段单位。

## 空音切换稳定性

已修正可从代码确认的风险：

1. 音源及效果器异步加载增加请求代次，丢弃过期回调，避免旧回调替换当前处理图或访问已卸载的图。
2. 卸载先停止音频处理，再销毁插件窗口和实例。
3. 捕获/恢复状态持有插件回调锁，避免仅设置暂停标志时与已经进入的处理块并发。
4. 主加载及取消编辑恢复使用原厂捕获的 samplerState，不把重新拼装的 KAM 当作插件组件状态；缺失原厂状态的方案报错，不载入空壳。
5. 增加本机 plugin-host.log，记录卸载、实例创建、状态恢复、处理图就绪阶段。不上传日志，不记录激活码。

尚不能断言上述风险就是用户闪退的根因。当前机器没有 Windows 空音3.11，未完成其运行时验证；本机编译和模拟参数测试不能证明“不再闪退”或“恢复后发声”。原厂状态恢复后无声仍属于必须实机验收的项，不标为已解决。
