# 0.15.1 容器音源交互与验收清单

## 本版目标

- 空音 `.KAI` 文件只用于确认音色库位置和数量，不再直接生成不可演奏的乐器卡片。
- 用户点击“添加空音乐器”，在 QinEngineV3 原厂界面实际选择乐器并确认后，才创建可演奏卡片。
- 保存插件标识、容器适配器、完整原厂状态和独立乐器身份；再次点击“演奏”恢复相同乐器。
- 新增通用容器音源框架。当前启用 `kong-v3`，并为 Kontakt、Falcon、三体保留独立适配器入口，未完成适配前不会伪装成可用。

## 用户流程

1. 扫描到 QinEngineV3 后进入“中国民乐 · 空音”。
2. 可选择音色库目录查看已安装 `.KAI` 文件数量；文件清单不生成乐器卡片。
3. 点击“添加空音乐器”。风吟加载一个全新的 QinEngineV3 实例并打开原厂界面。
4. 在原厂界面点击“＋”，选择一个乐器，确认 MIDI 通道和第一组立体声输出。
5. 回到风吟，填写乐器名称并点击“完成添加”。
6. 风吟检测原厂状态确实发生变化后保存，随后才显示乐器卡片。

## 验收清单

- [ ] 只选择包含 30 个 `.KAI` 的目录时，页面显示文件数量但不出现 30 张“待适配”卡片。
- [ ] 页面显示“添加空音乐器”入口。
- [ ] 点击入口会加载全新的 QinEngineV3 实例并打开原厂界面，避免沿用上一个乐器槽位导致叠音。
- [ ] 未在原厂界面添加乐器时点击完成，提示“尚未检测到新乐器”，且不创建卡片。
- [ ] 添加乐器并填写名称后，只创建一张对应名称的卡片。
- [ ] 点击卡片“演奏”可以恢复原厂插件状态并发声。
- [ ] 连续添加二胡、古筝等多个乐器时，各卡片恢复各自状态，不串音、不互相覆盖。
- [ ] 删除卡片后，仅删除该用户乐器，不修改 `.KAI` 音色库文件。
- [ ] 取消添加会恢复添加前正在使用的音色。
- [ ] 空音乐器不显示 SWAM 的乐器型号切换器；演奏页按名称匹配民乐图片，未知名称显示统一民乐占位。
- [ ] SWAM 扫描、默认方案、定制方案、技巧映射、音频输出和视频伴奏不受影响。

## Windows 实机必测

QinEngineV3 3.11 的真实状态块只能在已安装并授权的 Windows 电脑上验证。安装包测试时必须完成“添加一个乐器→关闭风吟→重新启动→点击演奏”的完整重启恢复测试；只有重启后仍能正确加载并发声，才视为通过。
