# 风吟 0.16.12 — 空气感

## 使用

在「定制音色 → 设置效果链」调节「空气感 · Air」（0–100%），可边吹边听。
保存为自己的方案后，切换回来或重启后加载会恢复该数值。
「软件设置 → 导出当前音色参数」继续保留，导出的 `fengyinEffects.air`
为 0–1（例如界面 67% 对应 0.67）。最终调音文件可用于后续预设整合。

旧方案、当前所有内置风格默认 Air=0，不改现有风格的其他参数。
本次不修改 SWAM 参数、MIDI 映射、气息适配或空音加载流程。

## 实现边界

- 自研并联高频细节增强，不是 Fresh Air 的算法复刻。
- 两个高通支路的拐点在 3.5 kHz / 9 kHz；低采样率时限制到奈奎斯特频率以下。
- 高频包络控制增强量，突出的高频瞬态获得较少增益；左右声道联动。
- 参数平滑约 15 ms，只平滑控制值，不延迟干声；无预读、无额外音频缓冲块。
- 音频回调不新增动态内存分配、锁、文件操作或插件。
- 只在乐器总线上、混响之前处理；不在伴奏或混合后的总线上处理。
- 原有安全限幅仍生效。关闭并完成平滑后精确旁通，不加噪声、不做新增响度补偿。
- 能突出已有空气细节，但不能凭空恢复不存在的气声，不保证单靠此参数复刻真人气包音。

## Windows 安装后试听验收

1. 在定制音色中选择次中音萨克斯，比较 Air=0、30、60 的高音细节，按听感调节。
2. 保存方案，切换其他风格再切回；重启并重新加载，Air 数值及效果应恢复。
3. 编辑时调整 Air，点取消，回到修改前效果；保存修改后应保留新值。
4. 播放伴奏时调 Air，伴奏不应被处理；录音应包含当前乐器 Air 效果。
5. 导出当前音色，核对 `fengyinEffects.air` 与界面百分比一致；SWAM 参数和状态仍完整导出。
6. 连续演奏和快速调节无新增爆音、断音；如原音已很亮或有底噪，降低 Air。
