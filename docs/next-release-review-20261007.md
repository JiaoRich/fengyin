## 2026-10-09 新增：1.1.7 build158 安装末尾类型错误（待下次构建修复）

- 用户指令：记录问题，下次构建修复；本次不修改生产代码、不发起构建。
- 现象：安装结束前弹出 `Runtime error (at 25:2044): Type Mismatch`。
- 证据：用户提供 `Setup Log 2026-10-09 #002.txt`；WebView2、ASIO4ALL、Fresh Air 安装器返回 0，VB-CABLE 第二次执行后设备检测返回 0。18:00:39.882，Fresh Air 返回后 `CurStepChanged` 抛异常；后续日志仍记录重启 Windows。

- 下次修复：改为合法字符参数（如 `#0, #0`），保留当前时间格式；补充标记写入前后日志及回归测试。不要因此修改正常 ASIO、气息曲线或音色链路。
- 影响：依赖更新标记可能未写入，自动刷新插件缓存可能未触发；安装器返回成功不等于插件实际加载验收通过。
