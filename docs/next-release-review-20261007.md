## 已有本地修改
- 技巧信号：映射的 Pitch Wheel 按偏离中位的幅度计算，回中为零；映射锁忙碌时不再放行到普通弯音。真实 MIDI 输入路径100轮触发/释放、锁竞争及取消映射后弯音恢复回归通过。尚不能据此确认录音变调的全部根因。
- 本轮本地 macOS 应用编译通过；22项 CTest 全部通过（含新增 MIDI 输入模拟）。不是 Windows 空音实机听感验收。
- 免费试用改为点击开始后连续1小时；按 CMake PROJECT_VERSION 独立保存记录，新版本可重新开始，同版本重启不重置，永久激活不受影响。发布不同版本须递增版本号，不按启动次数或 Git 提交重置。旧3天记录保留但不用于新策略。
- 录音固定命名：风吟演奏录音-YYMMDD-序号.wav，跨乐器共享当天序号，避开已有文件；不重命名旧文件。
- 埙独立图片；柳琴、三弦独立映射；唢呐、笙、中阮上下残片清理。
- 精简界面气息条位置、乐器可用空间居中、音量百分比和滑块对齐、技巧按钮主题化、音色标题吸顶。
- MIDI 有界诊断补记弯音及通道压力，避免遗漏变调来源。
