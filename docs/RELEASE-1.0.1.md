# 1.0.1 — 萨克斯预设加载修复候选

用户 Windows 日志显示，1.0.0 在 SWAM Alto Sax 3.9.4 初始化完成后又重复执行了 62 项初始参数和 22 项风格参数写入。可靠性报告为插件内 c0000005，偏移 0x96427c。没有调用堆栈，不能确认具体致错参数。

修改仅限预设写入流程：
- 首次应用不再批量重写插件初始参数。
- 切换稀疏预设只恢复上一套风格明确控制、下一套不包含的参数。
- 相同参数值和相同型号不再调用插件 setter，重复应用不再先恢复初始值再改回。
- 写入前后记录参数标识和值，便于进一步定位。
- 七套预设的参数数值、风吟效果链、智能适配、空音恢复逻辑不变。

自动检查覆盖首次加载、重复请求、稀疏风格切换及不干预无关参数。本机编译不能证明 Windows SWAM 崩溃已消除；需要测试高音、中音、次中音加载、吹奏与连续切换。
